# Documentação do Mouse Invisível

[Voltar à apresentação do projeto](../README.md).

Os guias separam uso, implementação e aceitação. O aplicativo tem um fluxo completo de
coleta e treinamento local; sua validação física continua pendente.

## Para começar

1. [Instalação e downloads](INSTALLATION.md): requisitos, `main`, pacotes e execução pelo código.
2. [Primeiro uso](QUICKSTART.md): câmera, exemplos, modelo, perfil, calibração e parada.
3. [Treinamento pessoal](LEARNING.md): coleta, separação de sessões e interpretação das métricas.

## Para contribuir

- [Arquitetura](ARCHITECTURE.md): componentes, dados, modelo tradicional e política de entrada.
- [Desenvolvimento](DEVELOPMENT.md): estrutura do repositório, comandos, CI e empacotamento.
- [Referência e créditos](REFERENCE.md): inspiração e o que foi possível verificar sobre o vídeo.

Os nomes das ações, schemas, flags de CLI e arquivos permanecem em inglês para corresponder
ao código. A orientação ao usuário está em português. Exemplos de teste são sintéticos e
não representam uma base de treinamento pronta para uso.
