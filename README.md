# Mouse Invisível

Original local-first, personally trained camera mouse for macOS, Windows and Linux X11.
Implementation follows [issue #1](https://github.com/sabino/mouse/issues/1).

This initial commit establishes `dev` as the first branch. A minimal `main` branch
will point to this same commit solely to allow draft PR review. Nothing is merged.

No real camera/input testing or gesture dataset exists yet. Native Wayland input is
out of scope for the first usable milestone; preview/training remain available.
